# LCON DIGITAL — PT/EN bilingual site

This version keeps the existing LCON DIGITAL design and adds a PT/EN language switcher in the header.

- Default language: Portuguese (PT-PT)
- Toggle: PT / EN in the header
- Slogan remains unchanged in English: “Bespoke Consulting. Tailored Digitally.”
- SAP product/module names and technical SAP terms are preserved where appropriate.
- Language preference is stored locally in the visitor's browser.
- Contact form remains connected to `/api/contact` and the existing Cloudflare Pages Function.

## Deployment

Replace the files in the existing GitHub repository with the contents of this folder. Cloudflare Pages will redeploy automatically.
